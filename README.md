# Meu Primeiro PR

Repositório criado para aprender o fluxo de contribuição no GitHub: branch, commit, push e Pull Request.

## Como este projeto funciona

Este é um repositório simples de prática. Cada melhoria pequena (correção de typo, ajuste de documentação, teste) é enviada por meio de um Pull Request, revisada e depois mesclada na branch `main`.
